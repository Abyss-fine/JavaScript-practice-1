## 5. Выполнение заданий

### Задание 1. Первый запуск JavaScript

Создан файл `hello.js`, выводящий два текстовых сообщения через `console.log()`.

Программа успешно запущена через Node.js. Также проверен запуск файла в браузере через `index.html`. Результат выполнения в браузере отображается в консоли разработчика.

### Задание 2. Типы данных

Созданы переменные со строковым, числовым и логическим значениями. С помощью оператора `typeof` определены их типы.

При проверке `null` оператор `typeof` вернул `object`. Это историческая особенность JavaScript.

### Задание 3. Расчёт прогресса

Реализован расчёт процента выполненных задач по формуле:

`progress = completedTasks / totalTasks * 100`

Добавлены проверки общего количества задач и допустимого количества выполненных задач.

### Задание 4. Планирование задач

Создана программа с вложенными циклами `for`, формирующая список задач для каждого дня.

### Задание 5. Отладка

В программе была допущена ошибка в имени переменной: `progres` вместо `progress`. При запуске возникло исключение `ReferenceError`.

После исправления имени переменной программа успешно выполнилась и вывела результат `80%`.

Иллюстрация отладки: `screenshots/debug.jpg`.

## 7. Инструкция по запуску

Команды выполняются из корневой папки репозитория:

```bash
node practice-01/js/hello.js
node practice-01/js/types.js
node practice-01/js/progress.js
node practice-01/js/plan.js
node practice-01/js/debug.js
```

Для проверки в браузере необходимо открыть `practice-01/index.html`, затем открыть инструменты разработчика и перейти во вкладку Console.
